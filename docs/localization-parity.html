Localization parity

Last reviewed: 2026-10-10 · Last updated: 2026-10-22 · Change: minor (the command line enables the OS IME and handles composition/commit, so single-line TEXT edits accept CJK input; previously: Brazilian Portuguese row updated and terminology reviewed; previously: Swedish catalog completed with the 95 strings added since; previously: Swedish catalog added: complete catalog, menu headings, native-speaker terminology review; previously: complete current Korean catalog with Hangul font coverage) · Target: Autodesk AutoCAD 2027 for Mac (26.0)

How far CADCraft's interface and drawing text are from AutoCAD's languages. Summarised in ROADMAP.md; work items in gaps.md.

What the target ships

Measured from the installed AutoCAD 2027 for Mac bundle by listing only (folder names, nothing read): Contents/Resources has Base.lproj (English), de, es, fr, it, ja, ko and zh_CN localizations, and Resources/Support has matching @de@ … @zh_CN@ folders. That is 8 interface languages on the Mac. AutoCAD for Windows also has language packs for Traditional Chinese, Brazilian Portuguese, Russian, Polish, Czech and Hungarian (Autodesk's published language-pack list, not measured here). AutoCAD's spell checker ships about 20 dictionaries (*.dct names in Resources/Support).

Drawing text in AutoCAD: TrueType and SHX big fonts (CJK), Unicode \U+ escapes, complex-script shaping and right-to-left text through TrueType, vertical SHX text styles.

What CADCraft has

  • A display-time string catalog (crates/ui-egui/src/i18n/, landed with #36): a TSV per language (context, English source, translation, @plural rows), Edit → Interface Language with Auto (system language), live switching, a saved choice, and tests for coverage, placeholders and plurals (localization.md). The Ukrainian and German catalogs have 989 rows each, covering menus, command labels, tool groups and tooltips, the Start page, tabs, status controls, object snaps, drafting prompts, property labels and dialogs. Engine diagnostics, CLI/MCP responses and command history stay English, and uncatalogued text falls back to English. For scale: about 1,160 unique capitalised string literals exist in crates/engine and crates/ui-egui (grep, 2026-10-10).
  • Drawing text: TrueType/OpenType/.ttc through skrifa with per-character font fallback and FONTALT, so CJK characters render (#173). DXF text is written with \U+ escapes so non-ASCII survives in R2000 files (#169). Lines with right-to-left text get the Unicode Bidirectional Algorithm and OpenType shaping with harfrust (Arabic, Persian and Urdu joining, lam-alef, ZWNJ, marks; Hebrew), in TEXT and MTEXT including wrapping (#287). Left-to-right lines are still placed one glyph per code point: no shaping for Devanagari and other Indic scripts, and no vertical text. SHX fonts are not read; our stroke font stands in.
  • Text input: egui/winit IME. The command line — which collects single-line TEXT edits and other prompt text — now enables the operating system IME while a prompt asks for text and shows composition (pre-edit) text until it is committed, so Chinese, Japanese and Korean input works there (#1761); egui's own text fields handle IME themselves. Several upstream IME fixes are queued as PRs (#110–#119: macOS Korean, emoji picker, Windows caret placement, X11 and Wayland), so CJK input is not yet reliable on every platform.

Other languages shipped: Ukrainian, Brazilian Portuguese, German, Czech, Russian, French, Italian, Korean, Swedish, Hungarian and Turkish. Czech, Swedish, Hungarian and Brazilian Portuguese cover the reference catalog and every marked UI literal; engine diagnostics and uncatalogued text remain English. AutoCAD for Mac ships 7 non-English languages (zh-Hans, es, fr, ja, de, ko, it); of those, CADCraft now ships German and Korean, and additionally Ukrainian, which AutoCAD for Mac doesn't ship.

Total to put all twelve at full: about 55–95 Opus 5.5 hours (catalog extension 4–6 h, ten translations 30–50 h, complex-script shaping and RTL 30–45 h), plus native-speaker review for each language, which needs humans. Translations parallelise fully once the catalog exists.
